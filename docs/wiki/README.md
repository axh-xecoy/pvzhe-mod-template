# PVZHE 开发 Wiki

这是模板对应游戏版本的可复用知识库。先理解玩家需求，再查当前版本的对应条目；不要求玩家知道资源名、类名或 Skill 名称，也不必每次重新解析整个游戏。

当前基线：[Windows C# 0.32.0增量入口](updates/0.32.0.md)；历史基线为[0.31.0](updates/0.31.0.md)与[0.30.0](0.30.0/overview.md)。先读当前入口的覆盖说明，再沿用下表正文；下表原有实测标签仍属于0.30，不自动升级为0.32结论。版本号相同但发布摘要不同也需核对差异；没有对应版本或实测与文档冲突时，只分析缺失/变化部分，明确迁移模板时使用pvzhe-template-upgrade。

“已实测”只覆盖条目列出的步骤、对象和方式；“静态确认”是接口/配置存在，不能推导行为成功；“待验证”不是可直接照搬的成功配方。只读当前任务所需条目，条目再指向代码和原始证据。

部分条目另标 **“用户实机记录，本模板待复核”**：这类内容来自维护者自己十几个 Mod 在同类发行上的实机调试与源码核对，判据具体但**不是本模板在本基线上的复跑结果**，版本也可能早于 0.30。使用前先用当前发行核对一次（发行 DLL/PCK、实际场景或一次最小运行），核对通过再按“已实测”对待；与页内既有实测结论冲突时以运行证据为准。写入这类内容时保留“谁在什么版本上观察到”，不把它改写成无需前提的通则。

现有0.30.0目录保存基线正文，后续版本按增量维护：未变主题直接引用，局部变化补差异，只有必要时新增受影响主题。版本号变化不要求创建一套完整Wiki或复制整个目录。当前入口须列清沿用来源、覆盖关系和目标版本证据状态；旧版实测不自动成为新版实测。Skills负责需求、制作流程和验收，示例提供代码；已有docs/recipes和复用目录是兼容导航入口，不在多处复制同一份机制说明。

维护规范见 [Wiki 维护与版本迁移](maintenance.md)。游戏升级必须同步核验 Wiki 的基线、操作路径、API、资源及验证状态，不只修改目录名或版本字段。

资源准备与位置预览的共享基础流程见 [资源缓存与捕获](../resource-cache-and-capture.md)。版本事实继续按主题页核对；缓存和透明组件渲染不要求源码。

玩家明确想自己自定义攻击/弹道时，默认使用[网页攻击编辑器](../attack-web.md)与对应Skill；普通开发不自动弹窗。预览持续等待确认/取消，轨迹示意与宿主运行契约分开验收。

外部社区资料的范围、版本与取舍见 [社区Skills参考](../community-references.md)。社区内容已按功能 [提取为本地Skills](../community-skill-extraction.md)，指导与本页运行事实分别记录，不将提取视为发行验收。

自有浮动控件的运行时中键拖动、右锚定和多Mod反馈协议见[游戏内拖拽布局](../ui-drag.md)；旧位置预览已弃用，具体运行证据以UI主题页为准。

模板工具与本地环境规则见[两槽游戏环境/使用者更新](../game-environment.md)；这部分不表示游戏新增接口。使用者同步官方模板与维护者适配新版游戏分别路由到project-update和template-upgrade。
